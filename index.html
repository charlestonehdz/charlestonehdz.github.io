// 01. PERFIL PROFESIONAL

Sobre mí

Compromiso con el análisis riguroso de procesos y el desarrollo de arquitecturas de software robustas y escalables.

Soy Carlos Hernández, desarrollador de software y profesional de proyectos TI, enfocado en el desarrollo de aplicaciones web y optimización de sistemas.

Mi enfoque técnico se basa en la convicción de que el código más eficiente es aquel que nace de un entendimiento profundo del negocio. No desarrollo pantallas aisladas: diseño sistemas integrados que optimizan tiempos operativos, garantizan la integridad de los datos y ofrecen interfaces administrativas claras y predecibles.

Cuento con experiencia en el ecosistema PHP (CodeIgniter y Laravel), modelado relacional en MySQL, MariaDB y SQL Server, consumo y construcción de APIs REST, además de interfaces interactivas con JavaScript vanilla y Bootstrap bajo entornos Linux y control de versiones riguroso con Git.
